# サンプルページ

これは汎用的なMarkdownページのサンプルです。

## 概要

このページは、Markdownファイルからコンテンツを読み込んで表示する汎用的なページテンプレートのデモンストレーションです。

## 機能

- **Markdownサポート**: 標準的なMarkdown記法をサポート
- **コードハイライト**: シンタックスハイライト付きのコードブロック
- **レスポンシブデザイン**: モバイルからデスクトップまで対応
- **カスタマイズ可能**: スタイルやレイアウトを簡単にカスタマイズ

## 使用例

### コードブロック

```javascript
function helloWorld() {
  console.log("Hello, World!");
  return "Hello from Markdown!";
}
```

### リスト

- 項目1
- 項目2
- 項目3

### 番号付きリスト

1. 最初の項目
2. 二番目の項目
3. 三番目の項目

### 引用

> これは引用文の例です。
> 複数行にわたる引用も可能です。

### テーブル

| 項目 | 説明 | 価格 |
|------|------|------|
| 商品A | 説明文A | ¥1,000 |
| 商品B | 説明文B | ¥2,000 |
| 商品C | 説明文C | ¥3,000 |

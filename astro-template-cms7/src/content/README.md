# Markdownコンテンツの使用方法

このディレクトリには、汎用的なMarkdownページで表示するコンテンツファイルを配置します。

## ファイル構成

```
src/content/
├── README.md          # このファイル
├── sample.md          # サンプルコンテンツ
└── [その他の.mdファイル]
```

## 使用方法

### 1. 新しいMarkdownファイルを作成

`src/content/` ディレクトリに新しい `.md` ファイルを作成します。

例: `src/content/about-us.md`

### 2. アクセス方法

作成したファイルは以下のURLでアクセスできます：

- 直接アクセス: `/markdown-sample` (サンプルページ)
- 動的ルーティング: `/markdown/[ファイル名]` (拡張子なし)

例: `about-us.md` → `/markdown/about-us`

### 3. サポートされているMarkdown記法

- **見出し**: `# ## ### #### ##### ######`
- **強調**: `**太字**` `*斜体*` `***太字斜体***`
- **コード**: `` `インラインコード` ``
- **コードブロック**: 
  ```javascript
  function example() {
    console.log("Hello World");
  }
  ```
- **リスト**: 
  - `- 箇条書き`
  - `1. 番号付きリスト`
- **リンク**: `[テキスト](URL)`
- **画像**: `![alt](画像URL)`
- **引用**: `> 引用文`
- **水平線**: `---` または `***` または `___`
- **テーブル**:
  ```markdown
  | 列1 | 列2 | 列3 |
  |-----|-----|-----|
  | データ1 | データ2 | データ3 |
  ```

## カスタマイズ

### 目次の表示/非表示

```astro
<MarkdownContent 
  content={markdownContent} 
  title={title}
  showToc={true}  // 目次を表示
/>
```

### スタイルのカスタマイズ

`src/components/MarkdownContent.astro` の `<style>` セクションを編集して、スタイルをカスタマイズできます。

## 注意事項

- ファイル名は英数字とハイフンのみ使用してください
- 日本語ファイル名は避けてください
- ファイルサイズは適切に保ってください（推奨: 1MB以下）

## トラブルシューティング

### ファイルが見つからない場合

1. ファイルが `src/content/` ディレクトリに配置されているか確認
2. ファイル名の拡張子が `.md` になっているか確認
3. ファイル名に特殊文字が含まれていないか確認

### 表示が崩れる場合

1. Markdown記法が正しく記述されているか確認
2. HTMLタグが正しく閉じられているか確認
3. 特殊文字が適切にエスケープされているか確認

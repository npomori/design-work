# 管理画面デザインサンプル

管理画面の色と代表画面を、API やデータベースなしで参照するためのプロジェクトです。

## 起動

```bash
pnpm install
pnpm dev
```

ブラウザで http://localhost:3000 を開きます。左下の「サンプル」からカタログへ移動できます。ダッシュボードとユーザ一覧はサイドバーからも開けます。ユーザ一覧の「編集」で編集モーダルが開きます。

## 画面

- デザインカタログ
- ダッシュボード
- ユーザ一覧と編集モーダル

記事エディタは `article-editor-standalone` を参照してください。ロゴ画像がリポジトリに無いため、文字のマークで代替しています。

# 公開画面デザインサンプル

公開サイトの色と代表画面を、API やデータベースなしで参照するためのプロジェクトです。

## 起動

```bash
pnpm install
pnpm dev
```

ブラウザで http://localhost:3000 を開きます。左下の「サンプル」から、カタログと各画面へ移動できます。

## 画面

- デザインカタログ
- ホーム
- 下層ページ（森林ボランティアとは）
- お知らせ一覧 / 詳細
- お問い合わせ（送信は成功メッセージのみ）
- ログイン（送信は失敗メッセージの見本）

地図、カレンダー、記事エディタは含みません。ロゴ画像とヒーロー写真がリポジトリに無いため、文字のマークと緑のグラデーションで代替しています。
